# Cosmos Explorer | Espaço Cibernético

Projeto acadêmico demonstrativo e portfólio profissional em astronomia, com HTML5, CSS3, JavaScript, SVG e armazenamento local. Protótipo desenvolvido com auxílio de IA.

## Funcionalidades
- Atlas de oito constelações e favoritos locais.
- Sistema Solar interativo com oito planetas.
- Biblioteca astronômica e quiz.

## Executar
Abra `index.html` em um navegador moderno.

## Publicação
No GitHub, acesse Settings > Pages > Deploy from a branch > main > / (root) > Save.

## Limitações
Representações ilustrativas, sem efemérides em tempo real, backend ou autenticação. Não é um planetário de precisão.
